## 项目描述

这是参考三院科协签到 Android 端的改版 APP（连 README 也参考吗），基于 Jetpack Compose 重新构建，保留原 UI 风格和基本功能，增加了一些新功能并修复了如旋转后无法保留页面状态、签到时杀掉APP重新进入后页面显示未签到等若干问题

目前已经完成签到与签退功能、查看与搜索在线人员、查看签到时长排行、帮他人签退与举办、自动定时签退等功能

后续：个人需求已解决，暂无后续想法

## Bug反馈

受限于重复签到返回的数据无个人签到基本信息原因，第一次下载安装如果输入学号签到成功发现名字等为null，那是因为之前在其他地方签过到，从而导致了重复，重新签退签到即可

目前已解决但可能因测试过少还会出现意外以及没考虑到的神人操作导致的Bug

目前能想到的神人操作：

- 签到后杀死APP然后切换自己的数据流量重新进入APP再换回科协网签到
- 在自己签到页面通过在线成员列表点击签退按钮为自己签退
- 省略号
